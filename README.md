# Estudar idiomas com IA — kit do aluno

Uma pasta que você abre no **Codex** (app do ChatGPT) ou no **Claude Code** e usa conversando em português.
A IA monta seus áudios de estudo, cria os cards do Anki, traduz textos frase a frase, treina conversação com você
usando **só o que você já estudou** e, se você quiser, transforma o áudio num vídeo simples (frase e tradução na tela).

**O método em uma frase:** estudar com conteúdo do **seu dia a dia**, em áudio e texto, repetir as mesmas palavras em
**contextos diferentes** e revisar no Anki **do português para o idioma** (lembrar de cabeça).

## O que você precisa

| Item | Custo | Para quê |
|---|---|---|
| ChatGPT com o app **Codex** instalado no computador (ou Claude Code) | plano pago do ChatGPT | é o agente que mexe nos arquivos e roda os scripts |
| **Anki** + complemento AnkiConnect | grátis | repetição espaçada |
| **Python 3.10+**, **ffmpeg**, `yt-dlp`, `pillow` | grátis | áudio, transcrição e vídeo (os scripts do kit) |
| ElevenLabs (opcional) | pago | voz mais natural; sem ele a voz grátis do Edge já funciona |

## Ordem de leitura

1. [COMECE-AQUI.md](COMECE-AQUI.md): a configuração, uma vez só.
2. Abra esta pasta no Codex e escreva: **"Leia o AGENTS.md e me ajude a configurar meu estudo."**
3. [docs/metodologia.md](docs/metodologia.md): o porquê de cada passo.

Quem lê o `AGENTS.md` é a IA, não você.
